# 微信读书网页版空格与滚轮翻页

保留空格下一页、滚轮向下下一页/向上上一页，以及输入框、目录和笔记面板避让。

## 安装与使用

[安装 v1.2.2](https://raw.githubusercontent.com/chaowushang/Eye-protection/main/wechat-read/wechat-read.user.js)。需要用户脚本管理器。旧版用户手动安装一次；沿用原 name/namespace，同一脚本只保留一个启用实例。

在 `/web/reader/书籍标识` 阅读页面使用。空格按一次翻一页；长按不连续翻页。鼠标位于正文或页面留白时，滚轮向下下一页、向上上一页。两次滚轮翻页至少间隔 **400 毫秒**；间隔内的滚动事件直接丢弃，不缓存，也不会在停止滚动后补翻。持续滚动可以继续翻页，最多约每秒 2.5 次；该限速不能保证一次长触控板手势只翻一页。

目录、笔记、输入框、按钮和独立滚动子面板保留原操作。Ctrl/Meta/Alt/Shift 修饰的操作、横向滚动及输入法组合输入均不介入。真实可见的模态对话框会暂停翻页，普通弹层类名不再导致整个阅读页面停用。

## v1.2.2 翻页兼容性修复（2026-11-01）

- 不再将特定正文类名和正文尺寸作为空格、滚轮生效的前提，避免阅读布局变化后无法翻页。
- 方向键从 body（未创建时退回 documentElement/document）派发一次，兼容不同层级的事件监听，避免重复派发。
- 移除对页面所有通用弹窗类名的全局阻断，仅避让事件所在面板、当前焦点和真实模态框。
- 允许阅读页留白区域的滚轮翻页；独立子面板仍可原生滚动。
- 改为 400ms 首次立即执行的限速，移除最小滚动距离和等待手势结束的锁；不排队，连续滚动不会永久锁死。

## v1.2.1 正式发布（2026-11-01）

安装及自动更新地址切换至 main，保留 v1.2 的翻页行为和防误触修复。

## v1.2 更新（历史行为，部分规则已由 v1.2.2 替换）

- 方向键只从 document 派发一次，避免重复冒泡到 window。
- 限定阅读路由及可见正文，避免干扰书架等页面。
- 过滤按键重复、组合输入及修饰键，避让可见弹窗和交互控件。
- 放行缩放和横向滚动，保留正文中独立面板的原生滚动。
- 将像素/行/页滚动单位归一化，累计 40px 才触发；同一连续滚动手势只翻一页。停止滚动超过 250ms 后可再次触发，避免惯性连翻。
- 支持 SPA 阅读路由变化，并补齐标准 `.user.js` 文件名及自动更新地址。

## 兼容性和限制

依赖网站对合成左右方向键的响应。正文选择器只用于识别原生滚动边界，不再决定脚本是否启用。网页键盘处理改版后仍可能失效；合成事件并非真实用户事件。如果不翻页，请记录浏览器、脚本管理器版本、阅读模式和问题页面路径后提交 Issue。没有新增设置面板；如需调整限速，可修改脚本顶部的 `WHEEL_COOLDOWN_MS`（默认 400）。
