# 微信读书网页版空格与滚轮翻页

保留空格下一页、滚轮向下下一页/向上上一页，以及输入框、目录和笔记面板避让。

## 安装与使用

[安装 v1.2.1](https://raw.githubusercontent.com/chaowushang/Eye-protection/main/wechat-read/wechat-read.user.js)。需要用户脚本管理器。旧版用户手动安装一次；沿用原 name/namespace，同一脚本只保留一个启用实例。

在 `/web/reader/` 阅读页面使用。空格按一次翻一页；长按不连续翻页。滚轮仅在正文容器内启用；目录、笔记、输入框、按钮和可滚动子面板保留原操作。Ctrl/Meta/Alt/Shift 修饰的操作、横向滚动及输入法组合输入均不介入。空格作用于阅读页面，但当焦点在交互控件或有可见弹窗时不翻页。

## v1.2.1 正式发布（2026-11-01）

安装及自动更新地址切换至 main，保留 v1.2 的翻页行为和防误触修复。

## v1.2 更新

- 方向键只从 document 派发一次，避免重复冒泡到 window。
- 限定阅读路由及可见正文，避免干扰书架等页面。
- 过滤按键重复、组合输入及修饰键，避让可见弹窗和交互控件。
- 放行缩放和横向滚动，保留正文中独立面板的原生滚动。
- 将像素/行/页滚动单位归一化，累计 40px 才触发；同一连续滚动手势只翻一页。停止滚动超过 250ms 后可再次触发，避免惯性连翻。
- 支持 SPA 阅读路由变化，并补齐标准 `.user.js` 文件名及自动更新地址。

## 兼容性和限制

依赖 `.readerChapterContent` / `.app_content` 正文选择器和网站对合成左右方向键的响应。网页结构、阅读模式或键盘处理改版后可能失效；合成事件并非真实用户事件。如果不翻页，请记录浏览器、脚本管理器版本、阅读模式和问题页面路径后提交 Issue。连续快速滚动会被视为同一手势，想再次翻页需短暂停顿；没有新增设置面板。
