# 护眼脚本

保留乡土黄、豆沙绿、浅色灰、淡橄榄四种配色、偏好记忆、按域名禁用和动态内容处理。

## 安装

[安装 v2.2.1](https://raw.githubusercontent.com/chaowushang/Eye-protection/main/eye-protection/huyan.user.js)。需先安装 Tampermonkey 或兼容用户脚本管理器。沿用旧脚本的 name/namespace 及 `colorValue`、`disabledSites` 存储键；升级后检查是否替换原实例，同一脚本只启用一份。根目录旧入口与本目录脚本保持一致。

## 使用

油猴菜单中选择四种颜色，或在当前站点启用/禁用，无需刷新。禁用会移除本脚本的背景覆盖。站点按 hostname 区分，子域名需单独设置。偏好由脚本管理器保存，不保证跨设备同步。旧管理器若不支持注销菜单，会使用固定的“切换此站启用/禁用”菜单。

## v2.2.1 正式发布（2026-11-01）

安装及自动更新地址切换至 main；保留根目录旧安装入口和原有配置。

## v2.2 更新

- 保留四种配色与旧版设置，切换颜色和站点开关立即生效。
- 只覆盖符合条件的元素背景色，不再清除后代元素背景、图片、渐变或阴影。
- 跳过透明及明显半透明背景、编辑区域和部分交互控件。
- 统一初始和动态扫描范围，重新评估 class/style/主题属性变化，移除不再符合条件的标记。
- 每帧最多检测 120 个待处理元素，合并重复节点，并在窗口尺寸、系统配色变化时重新评估。
- 恢复异常存储值，保持菜单数量稳定。

## 范围及限制

保持原有保守尺寸规则：不修改 html/body，跳过小于 50×20 的区域；视口宽于 800 时跳过超过视口 95% 宽度的容器。因此并非整个页面都会变色。不是医疗护眼工具，也不保证降低蓝光。CSS 背景图、Shadow DOM、Canvas、复杂自定义主题及更高优先级样式可能需要站点适配。跨标签页设置变化在重新加载后读取。
